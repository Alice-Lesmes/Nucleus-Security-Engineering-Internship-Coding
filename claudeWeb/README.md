# Calculator app

Svelte front-end + Python backend (`calculator.py` via `server.py`).

## Run

Terminal 1 (backend, Python 3.10+, no dependencies):

    python server.py

Terminal 2 (front-end):

    npm install
    npm run dev

Open the URL Vite prints (http://localhost:5173). Keyboard works too:
digits, operators, Enter or = to evaluate, Backspace, Esc to clear.
